# GitHub submission checklist

## 1. Create the repository
Create a **public** repository named `uniflow-student-planner` on GitHub. Do not initialize it with a README if you plan to push this local project as-is.

## 2. Push the project
From this directory:
```bash
git init
git add .
git commit -m "Add UniFlow specification and MVP"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/uniflow-student-planner.git
git push -u origin main
```
Replace `YOUR-USERNAME` with your actual GitHub username.

## 3. Create Issues
Create one issue for each Markdown file in `_docs/github-issues/`. Copy the title and body. Use the actual issue number in comments; GitHub numbers may differ from the draft labels.

## 4. Process every issue
For each issue:
1. PM grooms it using `_docs/task-template.md`.
2. Review and save the groomed criteria in the issue description.
3. Engineer implements it, tests it, commits, and comments; do not close it.
4. QA independently runs tests and posts a PASS/FAIL comment with evidence.
5. If FAIL, fix and retest.
6. Close only after QA PASS.

## Deadline warning
The assignment requires issue open and close timestamps to be before the deadline. Work backwards from the real deadline, and do not create fake history or close unverified work. GitHub timestamps are generated by GitHub and cannot be honestly backdated through ordinary issue creation.

## Final submission
Submit the real URL:
`https://github.com/YOUR-USERNAME/uniflow-student-planner`
