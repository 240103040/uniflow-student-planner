# Design system

## Visual direction
Calm, clean, student-friendly interface. Use a light background, white cards, dark readable text, and a restrained violet accent.

## Layout
- Header: UniFlow wordmark and short description.
- Main content: page title, task creation form, filter controls, assignment list.
- Each assignment is displayed as a card or compact row.
- Form fields must have visible labels.
- Status must be communicated with text, not colour alone.
- Empty state should explain that no assignments match the current filter.

## Accessibility
- Use semantic HTML.
- Labels must be associated with form inputs.
- Interactive controls must be keyboard accessible.
- Maintain readable contrast and visible focus.
- Error messages must be understandable and associated with the relevant field.

## Responsive behaviour
- At narrow widths, stack the form and task list vertically.
- Avoid horizontal scrolling.
- Buttons and inputs should be comfortably tappable.
