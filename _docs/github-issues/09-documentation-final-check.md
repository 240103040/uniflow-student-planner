# Complete documentation and final verification

## Goal
Ensure a new developer can set up, run, and test UniFlow using the repository documentation.

## Acceptance criteria
- [ ] README documents prerequisites, environment setup, migrations, run command, and test command.
- [ ] `AGENTS.md` links to relevant project documents and gives accurate commands.
- [ ] `_docs/plan.md`, `_docs/process.md`, role docs, design system, API, and testing docs match implementation.
- [ ] `python manage.py check` passes.
- [ ] `pytest` passes.
- [ ] No documentation claims deployment or features that are not implemented.

## Out of scope
- Cloud deployment and production secret management.

## Constraints
- Follow `_docs/process.md`.
- Record real command output; never fabricate QA evidence.
