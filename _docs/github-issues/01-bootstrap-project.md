# Bootstrap Django project

## Goal
Create a minimal Django project that runs locally and has a passing smoke test.

## Acceptance criteria
- [ ] Dependencies and project configuration are declared in `pyproject.toml`.
- [ ] `python manage.py check` completes successfully.
- [ ] `pytest` runs at least one smoke test successfully.
- [ ] README documents local setup and test commands.
- [ ] No assignment features are added in this issue.

## Out of scope
- Assignment model and CRUD behaviour (follow-up issue #2).

## Constraints
- Follow `_docs/plan.md`, `AGENTS.md`, and `_docs/testing-guidelines.md`.
- Use Python and Django; do not add dependencies without review.
