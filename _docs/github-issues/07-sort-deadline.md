# Sort assignments by deadline

## Goal
Display assignments with the earliest due date first.

## Acceptance criteria
- [ ] Assignment list is ordered by due date ascending.
- [ ] Assignments with the same date have deterministic secondary ordering.
- [ ] Sorting works together with each status filter.
- [ ] Test demonstrates earlier dates appear before later dates.
- [ ] The UI or documentation accurately reflects the sort behaviour.

## Out of scope
- User-selectable multi-column sorting.

## Constraints
- Follow `_docs/api.md` and `_docs/testing-guidelines.md`.
